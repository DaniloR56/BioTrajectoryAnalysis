# BioTraj Analysis Tools

This directory contains the principal analysis utilities distributed with
BioTraj v1.2.

## 1. AntTrajectoryAnalysis.py

Main BioTraj trajectory-analysis program.

It calculates conventional trajectory descriptors and the spatial and
temporal information-geometric analyses described in the BioTraj
publication.

Example:

    python3 AntTrajectoryAnalysis.py ant_tracks.csv \
        --output BioTraj_results \
        --info-geometry \
        --info-grid-x 20 \
        --info-grid-y 12 \
        --info-angle-bins 18 \
        --info-min-samples 30 \
        --info-bootstrap 200 \
        --temporal-info-geometry \
        --temporal-window-frames 900 \
        --temporal-step-frames 900 \
        --temporal-min-samples 100 \
        --temporal-bootstrap 200 \
        --fps 60

The spatial information-geometric analysis produces, among other files,

    info_geometry_cells.csv

which can subsequently be combined with independently defined scene
annotations.

## 2. BioTraj_Scene_Annotator.py

Interactive utility for defining physical, biological, and observational
features directly on a reference image, normally the first frame of a
recording.

Run with:

    python3 BioTraj_Scene_Annotator.py FirstFrame.jpg

The annotator supports:

- polygonal regions;
- circular regions;
- polylines;
- surface regions;
- surface transitions;
- biological features;
- physical constraints;
- observation boundaries;
- artifact/exclusion masks.

Annotations are stored in JSON format using original-image pixel
coordinates.

The annotations should, whenever possible, be defined independently of
the Fisher--Rao result to avoid selecting regions retrospectively from
the information-geometric map.

## 3. BioTraj_Annotated_FR_Analysis_v1_1.py

Combines independently defined scene annotations with the spatial
Fisher--Rao results generated by `AntTrajectoryAnalysis.py`.

Example:

    python3 BioTraj_Annotated_FR_Analysis_v1_1.py \
        --annotations FirstFrame_scene_annotations.json \
        --info-cells BioTraj_results/info_geometry_cells.csv \
        --tracks ant_tracks.csv \
        --image FirstFrame.jpg \
        --grid-x 20 \
        --grid-y 12 \
        --output annotated_FR_results

The program generates annotation-aware cell tables, regional summaries,
transition summaries, distance-from-transition diagnostics, metadata,
and graphical overlays.

Annotations marked with

    exclude_from_tracking_analysis: true

are treated as quality-control exclusion regions.

## Annotation-aware workflow

The intended workflow is:

    video
      |
      v
    AntTracking.py
      |
      v
    ant_tracks.csv
      |
      v
    AntTrajectoryAnalysis.py
      |
      +----> info_geometry_cells.csv
      |
      |
    reference image
      |
      v
    BioTraj_Scene_Annotator.py
      |
      v
    scene_annotations.json
      |
      +----------------------+
                             |
                             v
              BioTraj_Annotated_FR_Analysis_v1_1.py
                             |
                             v
                   annotation-aware results

Annotation-aware analyses are descriptive. Spatial cells from a single
recording should not automatically be treated as independent biological
replicates, and Fisher--Rao heterogeneity alone does not identify a
biological or physical mechanism.
